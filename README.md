## 🚀 About The Project

**AQUAZAR** is a cutting-edge, single-file Flask application built for a futuristic water delivery business. Designed with a stunning cyber-space aesthetic, it features deep-space gradients, drifting CSS stars, glowing neon interfaces, and an animated water vortex. 

Under the hood, it seamlessly integrates a Python/SQLite backend to handle live water bookings, dynamic bulk-price calculations, and customer contact requests—all routed through smooth AJAX calls without a single page reload.

## ✨ Key Features

- **Cyberpunk UI & Animations:** Custom CSS-generated starry layers, pulsing neon buttons, and an animated central water vortex.
- **Dynamic Price Calculator:** A real-time JavaScript widget that calculates bulk water pricing based on quantity and delivery distance.
- **AJAX Order Launch System:** Smooth modal-based ordering system that instantly logs customer bookings into the database.
- **IoT Smart Refill Ready (UI):** Features a high-tech layout supporting automated subscription models.
- **Auto-Seeding Database:** Automatically initializes and populates the SQLite database (`aquazar.db`) with dummy users, orders, and subscriptions on the first run.
- **Single-File Architecture:** The entire full-stack platform (HTML, CSS, JS, Python, SQL) runs from one highly optimized script.
